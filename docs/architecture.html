01

The two-process map

The thing you see (the 🧠 menu-bar icon) is a lightweight app. The brains live in a separate, always-on server. The app never holds a model — it just sends text and draws the answer. Keeping them apart means the app can rebuild or crash without ever reloading a multi-gigabyte model.

03

Two models, two jobs

The core design decision: the detector is the judge, the brain model is the illustrator. They're never swapped — proven by experiment that the text model detects better, and the brain model can only show, not decide.

The Detector

Judge · always resident
Model
Llama-3.2-3B Instruct (4-bit)
Job
Names the persuasion tactic + a real confidence
Size
~2 GB, stays loaded for speed
Speed
~2–3s per verdict
Why
The better detector — text beats the brain map

TRIBE v2

Illustrator · loaded on demand
Model
Meta's fMRI foundation model
Job
Predicts where in cortex the words land
Size
~7 GB, loaded & freed per scan
Speed
~15s warm, ~2min cold
Why
Never a detector — visceral picture only
The honesty rule baked into the wiring

TRIBE only sees the cortex, not deep structures like the amygdala. So the UI says "engages your value / language-evaluation cortex," never "fires your fear center." The architecture is built to never overclaim.

06

Performance & testing

The detector is fast and now has a real report card.

~0.6s per ⌘B (was ~4s) gate PR-AUC 0.92 · recall 0.66 calibration ECE 0.37 → 0.10 ~45% external (vs 80% self-authored)
Two-stage gate
A yes/no "is this manipulation?" first — stops greetings/facts/reviews being forced into a tactic.
External test set
300 independently-labeled examples across 6 vectors (dark-patterns + fallacy + clickbait) — the honest, never-tuned-on number.
bench_full.py
Macro-F1 + Wilson/bootstrap CIs, per-class, confusion, MCC, gate PR-AUC, and confidence calibration (ECE).
pytest suite
Contract, behavior, benign + realistic guards, taxonomy-drift, robustness.

Measured honestly, then improved. On self-authored data it looked ~80% accurate; on 300 external, never-tuned-on examples across 6 vectors it's ~45% — the overfitting gap laid bare. Fixes followed (validated on a held-out half): un-sharpen the gate so its ranking is usable (PR-AUC 0.92) and its threshold tunable (recall 0.66), Platt-calibrate the confidence so the % means P(correct) (ECE 0.37 → 0.10), abstain when a label is unclear, and split fomo (scarcity) from false-urgency (the clock) — the biggest technique blur (fomo recall 0.05 → 0.70). Contextual calibration was evaluated and gave no gain (the yes/no gate already avoids the bias it targets). The detector tells manipulation from benign decently; some tactic labels still blur — and we say so.
