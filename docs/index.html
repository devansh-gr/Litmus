How it works

Two models, each doing only what it’s genuinely good at

The whole design falls out of one honest result: the brain model is a worse detector than the text it’s built from (100% vs 75% in a fair test — information theory guarantees it). So detection is the language model’s job; the brain map exists to make manipulation felt, never to raise accuracy.

Detection · the verdict

A local language model names the technique

Llama-3.2-3B (4-bit, ~2 GB, Apple-native MLX) scores the log-probability of every candidate label and returns the most likely one with an honest confidence. Fast — about 0.6 s per ⌘B.

accurate · always resident · the judge
Interpretation · the picture

TRIBE v2 shows where it lands in cortex

Meta’s fMRI foundation model predicts cortical activation for the text, z-scored against a neutral baseline. It’s cortex-only, so we say “engages your value / language cortex,” never “fires your fear center.”

visceral · loaded on demand (~15 s) · never the detector
Detection is two-stage

A gate first, then the label

A single classifier forced every input toward its nearest label — a friendly “Hello!” came back “Hype 84%.” The fix is a clean yes/no gate that decides intent before naming a technique.

text ─▶ [ Stage 1 · is this manipulation at all? ] ──no─▶ “No manipulation ✓” │ yes ▼ [ Stage 2 · which of 14 techniques? ] ─▶ verdict + confidence

The 14 techniques span two families: broadcast persuasion (fear, false urgency, FOMO, hype, authority, social proof, dopamine bait, outrage, tribal, awe) and interpersonal manipulation (guilt-tripping, gaslighting, love-bombing, blame-shifting / DARVO).

Measured honestly

Most detectors quote accuracy on data the authors wrote. This one doesn’t.

Every number below is on 300 independently-labeled examples from public datasets — dark patterns, logical fallacies, clickbait — that we neither wrote nor tuned on. The self-authored number reads ~80%; that’s grading your own homework.

The honest read: the detector tells manipulation from benign very well (gate PR-AUC 0.93) and names the technique decently (~62%). It transfers to a completely independent dataset at 65% — so it learned the patterns, not the phrasings. What’s left is the ceiling of a small on-device model, and we say so plainly. Full methodology, confidence intervals, and the failure modes are in the benchmarking write-up.
